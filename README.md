# 翠境防线 · 三线纵深

Unity 3D 塔防游戏。现在不是单路线平面原型，而是**三条独立道路、三层高度、立交桥和真实坡道**构成的立体战场。

## 直接运行

双击根目录的 **开始游戏.cmd**，或运行 **Builds/ThreeFronts/Verdant.exe**。

- Unity 工程：本目录，编辑器版本 **6000.6.0f1**。
- 主场景：`Assets/Scenes/Verdant.unity`，打开后点击 Play。
- 场景在运行时生成；编辑模式下只有 Game Controller 是正常现象。
- 请保留 exe 旁边的 `Verdant_Data`、`UnityPlayer.dll` 等文件，不要只拷贝 exe。
- 旧的 `Builds/Windows`、`Builds/Release`、`Builds/Vertical` 是先前版本；为了不打断已经运行的游戏，未覆盖或删除。**请以 ThreeFronts 为新版。**

## 三线立体地图

| 道路 | 颜色 | 实际高度 | 特征 |
| --- | --- | --- | --- |
| A 林间地道 | 金色 | 0 米 | 地面曲折长线，会从高架桥下穿过 |
| B 空中栈桥 | 青色 | 3.6 米 | 独立高架桥、桥墩与护栏，最后沿坡道下降 |
| C 山巅坡道 | 紫色 | 6.4 → 3.6 → 0 米 | 从山顶出发，穿过两段下坡，最终汇入核心 |

- 前两波从 A、B 两路来袭，第 3 波起三路交替刷怪、同时在场。
- 三路在核心汇合，但没有强迫敌人切换线路的假分叉。
- 共 **18 个分层塔位**，地面 9 个、中层 7 个、山巅 2 个。
- 射程按**炮塔头部到敌人中心的三维距离**计算，不是忽略高度的平面距离。
- 近距离可以跨层射击；隔着很大的高度差则不能命中。射程以三条圆环表现为球形。
- 天火、爆破、治疗、燃烧和首领干扰也按三维距离判定；桥下敌人不会因为画面重叠就被桥上爆炸击中。
- 新增地形遮挡：桥面、桥墩、山体和悬崖属于实体地形，直射塔会被挡住；迫击炮采用抛物线弹道，可以越过低矮障碍，但撞到实体也会提前爆炸。索敌、主动技能和范围伤害同样会检查地形视线。

| 操作 | 功能 |
| --- | --- |

| 鼠标滚轮 | 缩放战场 |

| U | 将选中塔从 1 级升到 2 级 |
| Tab | 切换索敌优先级：终点最近 / 生命最强 / 治疗师优先 |
| Q | 天火瞄准，再点击某一层道路施放 |

| E | 全塔超频 |

## 塔与分支进化

初始 **380 金币、20 生命**。塔最多 3 级：1→2 为通用升级，2→3 必须选择一条不可反悔的进化分支。

| 基础塔 | 价格 | 分支一 | 分支二 |
| --- | ---: | --- | --- |
| 脉冲哨塔 | 90 | **鹰眼穿甲**：更远射程、高单发伤害、无视护甲，但射速更慢 | **连锁闪电**：攻击弹射附近两个目标 |
| 霜晶塔 | 125 | **永冻领域**：68% 减速与短暂冻结 | **霜裂共鸣**：更大范围、使目标承受伤害增加 30% |
| 花火迫击炮 | 155 | **攻城重炮**：2.2 米爆破、85% 护甲穿透 | **熔火封锁**：留下持续 3.5 秒的燃烧区域 |

可在右侧面板出售塔，默认返还总投入的 70%；回收遗物可将其提升到 90%。

## 主动技能

- **Q 天火轰击**：点击具体层级的道路/地面，1 秒后产生三维范围爆炸。基础冷却 26 秒。
- **W 极寒领域**：冻结全场敌人 3.2 秒，首领时间减半。基础冷却 36 秒。
- **E 全塔超频**：8 秒内攻速提高 65%，同时免疫首领干扰。基础冷却 40 秒。
- 冷却只在战斗进行时恢复，暂停和波次准备阶段不能空等刷新。

## 敌人与战役

**15 波**具有固定编排的战役，提供标准 / 老兵 / 噩梦三种难度，第一波开始后锁定。默认老兵。

敌人包括普通行者、快速斥候、重甲兵、护盾兵、治疗师、孢群和首领。

- 重甲：减免普通伤害，穿甲、爆破可以克制。
- 护盾：护盾先于生命承伤；霜晶对护盾造成 3 倍伤害。
- 治疗师：每 3 秒治疗三维范围内的同伴，应优先处理。
- 首领：第 5、10、15 波出现，半血狂暴；施放有预警圈的区域干扰，使附近塔暂停开火。
- 普通敌人漏过扣 1 生命，首领扣 4。清除最后一波获胜，生命归零失败。

每通过 3 波（最后一波除外），获得一次**遗物三选一**，可以增加伤害、射程、攻速、击杀金币、恢复生命、强化技能或提高回收收益。当前采用固定轮换的遗物候选列表，便于重复验证，并不是随机生成关卡。

### 初始策略提示

先覆盖 A、B 两条路线；第 3 波之前给山巅 C 线留一笔建塔预算。不要把所有金币都堆在某一层。高架转角适合控制塔，地面出口适合补漏；对治疗师切换优先级，对首领提前保留超频。

## 工程结构

| 文件 | 职责 |
| --- | --- |
| `Assets/Scripts/DefenseGame.cs` | 状态机、三路刷怪、金币、生命、鼠标交互与射程球 |
| `Assets/Scripts/MultiLevelWorld.cs` | 三层地图、独立路线、坡道桥梁、分层塔位、环绕相机 |
| `Assets/Scripts/WorldBuilder.cs` | 模型生成、材质、敌人/炮塔外观、光环特效 |
| `Assets/Scripts/Combat.cs` | 三维移动与索敌、护盾/护甲/治疗、首领干扰、分支弹药 |
| `Assets/Scripts/Strategy.cs` | 15 波配置、难度、技能、遗物和进化 |
| `Assets/Scripts/DefenseHUD.cs` | 中文 HUD、道路图例、情报、技能、进化和遗物界面 |
| `Assets/Scripts/SmokeTest.cs` | 机制与全战役集成检查（生命周期阶段使用测试强化） |
| `Assets/Scripts/BalanceTest.cs` | 不加金币/属性的正常经济自动战役 |
| `Assets/Editor/ProjectSetup.cs` | 一键创建场景、Windows 构建 |

模型、音效均为程序生成，不依赖商店素材或第三方插件。使用内置渲染管线、D3D11、旧版 Input 与 IMGUI。中文字体通过 Windows Microsoft YaHei 动态加载；没有随包分发字体。

## 构建与测试

```powershell
.\Build.ps1
.\Test.ps1
.\Test-Balance.ps1
```

- `Logs/build.log`：构建日志。
- `Logs/smoke.log`：机制集成检查。
- `Builds/ThreeFronts/smoke-result.json`：检查结果。
- `Builds/ThreeFronts/balance-standard.json`、`balance-veteran.json`：自然经济战役结果。
- `Builds/ThreeFronts/preview-three-fronts.png`：真实引擎渲染的测试布阵，不是概念图。

集成测试覆盖三条路线共用终点、三层实际高度、坡道移动、三维/跨层射程、桥面/岩体遮挡与弹丸碰撞、建造与经济、六种进化、护甲/护盾、冻结、超频反干扰、技能冷却、遗物、15 波胜利及失败流程。当前 SmokeTest 为 57 项检查。

自然经济测试只使用正常购买和施放接口，没有追加金币或加强炮塔。它证明一套自动策略可通关，并不意味着所有布阵都能通关或已穷尽难度平衡测试。

## 当前范围

可玩的单关卡塔防原型；没有存档、关卡编辑 UI、联网、移动端适配或射线遮挡系统。关卡与数值可在 C# 配置中继续扩展。
